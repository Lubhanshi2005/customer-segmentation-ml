# Customer Segmentation Using Machine Learning

## Project Overview
This project applies unsupervised machine learning to segment 200 customers into five distinct groups based on their age, annual income, and spending score.

The goal is to identify customer personas and generate actionable business recommendations for targeted marketing strategies.

## Objectives
- Explore customer demographic and spending data.
- Apply clustering techniques to identify customer segments.
- Evaluate cluster quality using the Silhouette Score.
- Use PCA for dimensionality reduction and visualization.
- Develop customer personas and business recommendations.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab
- GitHub

## Key Results
- *Total customers analyzed:* 200
- *Customer clusters identified:* 5
- *Best Silhouette Score:* 0.5547
- *PCA variance explained:* 100% for the selected components

## Business Insights
- *Cluster 0:* Use loyalty rewards and personalized offers.
- *Cluster 1:* Promote premium products and exclusive benefits.
- *Cluster 2:* Offer affordable options and reward points.
- *Cluster 3:* Use targeted campaigns to understand and encourage spending.
- *Cluster 4:* Focus on budget-friendly products and value bundles.
